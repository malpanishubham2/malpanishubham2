I build enterprise data platforms and wire them up to AI so non-technical people can actually use the data they're sitting on. Most of my work lives in private repos, but here's the shape of it.

### What I've built

**Enterprise data warehouse** -- built from zero on Microsoft Fabric. 21+ source systems consolidated into a medallion-architecture warehouse serving 400+ users across 8 business units. Config-driven PySpark ingestion, 125 production pipelines, 98.2% success rate.

**AI analytics layer** -- 7 MCP servers (~8,200 lines of Python/TypeScript, 65 tools) connecting Claude to 200+ warehouse tables. People query data in plain English instead of writing SQL. 8-layer query security, 3-tier observability. This surfaced $7.6M in unrealized revenue that leadership didn't know existed.

**AI entity matching** -- LLM-powered fuzzy matching between CRM and ERP with human-in-the-loop approval via email. Cut data rejection rates from 25% to 5%.

**LLM pipeline diagnostics** -- agent that ingests failure logs, compares against source code, and outputs root cause + fix instructions. MTTR went from hours to minutes.

**Infrastructure as code** -- 17 Terraform modules, 84 .tf files, 3 environments. Zero to automated gated deployments in 8 weeks.
